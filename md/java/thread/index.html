          # Java 并发与 J.U.C

          并发编程需要同时保证正确性、响应性和资源可控性。本目录从线程与 Java 内存模型开始，逐步进入锁、原子类、线程池、并发容器和结构化并发。

          # 学习目标

          • 理解线程生命周期、可见性、有序性、原子性和 happens-before。
          • 能正确使用锁、原子类、并发工具和线程池。
          • 能设计停止、超时、隔离、背压和监控机制。

          # 学习顺序

          1. Java 并发知识体系
          2. Java 并发理论基础
          3. Java 并发线程基础
          4. J.U.C 知识体系详解
