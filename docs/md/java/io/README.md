# Java IO 与 NIO

IO 代码直接决定文件处理、网络服务和中间件客户端的吞吐与稳定性。本目录从阻塞 IO、缓冲与编码过渡到 Channel、Buffer、Selector 和异步模型。

## 学习目标

- 正确选择字节流、字符流、缓冲流和文件 API。
- 理解同步/异步与阻塞/非阻塞的区别。
- 能设计背压、超时、资源关闭和大文件处理策略。
