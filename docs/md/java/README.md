# Java 工程基础

Java 是业务后端、Spring 应用和 AI 应用服务底座的重要组成部分。本领域按照“会写代码、理解运行时、定位生产问题”的能力递进组织，重点覆盖 Java 语言、集合、并发、IO/NIO、JVM 与诊断工具。

## 学习目标

- 掌握 Java 类型、面向对象、异常、泛型和常用语法的工程用法。
- 能根据访问模式选择集合、并发容器和线程模型。
- 理解 JVM 内存、类加载、字节码和垃圾回收对应用行为的影响。
- 能使用日志、JDK 工具和指标定位 CPU、内存、死锁、卡顿等问题。
