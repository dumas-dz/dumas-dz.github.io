# Java 基础与面向对象

本目录从语言规则和面向对象设计两个层面建立 Java 编码基础，适合准备进入 Spring 后端开发、复习 Java 核心语法或统一团队编码习惯的开发者。

## 学习目标

- 正确使用类型、值语义、不可变对象、异常和泛型。
- 用封装、继承、多态和组合建立清晰的对象边界。
- 能识别过度继承、贫血模型、可变共享状态等设计问题。

## 学习顺序

1. [Java 基础知识体系](./java-basic-bok.md)：类型、字符串、异常、泛型与现代 Java 语法。
2. [Java 面向对象基础](./java-basic-oop.md)：对象建模、接口、抽象类、组合和 SOLID。
