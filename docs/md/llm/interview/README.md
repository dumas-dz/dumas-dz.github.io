# 面试与复盘

本目录把高频面试题还原为工程问题，重点训练“原理 -> 方案 -> 权衡 -> 落地”的回答方式，而不是背诵结论。

## 内容索引

- [AI 应用开发面试题](./ai-interview-qa.md)：RAG、Agent、MCP、多 Agent、上下文、成本与 Transformer 基础。

## 使用建议

1. 先独立给出方案，再对照文档补充遗漏环节。
2. 回答时说明适用规模、失败模式、评测方法和成本影响。
3. 将自己做过的项目与题目关联，避免只讲通用方案。
4. 面试结束后记录追问，回填到相关知识文档。
