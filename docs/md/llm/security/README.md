# AI 安全与治理

> 内容状态：已完善  
> 最后审阅：2026-11-16  
> 适用范围：RAG、Agent、MCP、Workflow、多租户 SaaS、私有化部署与生成式 AI 工具链。

AI 安全的边界不仅在模型，而在数据、检索、工具、身份、供应链和运营流程。核心假设是：模型输出不可信，外部内容可能包含攻击，工具权限决定最坏影响。

## 学习目标

- 识别间接提示注入、越权工具调用、数据外泄和模型幻觉风险。
- 使用身份、授权、输入隔离、输出过滤和工具策略实施纵深防御。
- 对个人信息、商业秘密和调试数据实施分类、脱敏、最小保留。
- 建立不可抵赖的审计事件、风险分级和发布治理。
- 通过红队和回归集验证防护，而不是依赖单个关键词过滤器。

## 威胁模型

| 资产 | 威胁 | 影响 |
| --- | --- | --- |
| 系统提示与策略 | 提示泄漏、规则覆盖 | 防护失效、商业秘密泄露 |
| 用户与企业数据 | 跨租户访问、PII 外泄 | 合规、声誉和财产损失 |
| 工具与业务系统 | 注入驱动调用、参数篡改 | 删数据、发消息、错误工单 |
| 模型与知识库 | 投毒、过期、错误引用 | 错误决策、事实性风险 |
| 供应链 | 恶意模型、插件、MCP Server | 代码执行、凭据泄露 |
| 审计与运维 | 日志泄密、管理员越权 | 无法追溯、二次泄露 |

## 纵深防御

```text
身份认证 -> 租户隔离 -> RBAC/ABAC -> 输入分类
         -> 检索边界 -> Prompt 隔离 -> 模型
         -> 输出校验 -> 工具策略 -> 二次确认
         -> 审计/告警 -> 红队/回归 -> 应急响应
```

## 风险分级

| 等级 | 示例 | 最低控制 |
| --- | --- | --- |
| L1 低风险 | 文本润色、内部摘要 | 基础权限、内容过滤、日志 |
| L2 中风险 | 客服回答、知识检索 | 引用、质量门禁、输入隔离、审计 |
| L3 高风险 | 创建工单、发送消息、修改数据 | 最小权限、二次确认、幂等、完整审计 |
| L4 极高风险 | 资金、权限、生产控制、敏感决策 | 人工审批、强隔离、双人控制、禁止全自动 |

## 上线安全检查表

- [ ] 身份从 Gateway 到模型、工具和数据库全程传播，禁止服务账号越权代替用户。
- [ ] 每个租户的向量库过滤、对象存储和缓存键都有租户隔离测试。
- [ ] 外部文档、网页、邮件、工具返回都标记为不可信数据，不能改变系统策略。
- [ ] 高风险工具使用显式允许列表、参数 Schema、速率限制和二次确认。
- [ ] 输出过滤覆盖 PII、凭据、系统提示、恶意链接、危险指令和代码。
- [ ] 审计记录谁、何时、以何身份、对何资源、执行何操作、结果如何。
- [ ] Prompt、模型、知识库、工具和策略均可版本化、审批和回滚。
- [ ] 红队覆盖直接/间接注入、越权、数据外泄、多轮诱导和工具链攻击。
- [ ] 有凭据泄露、错误操作和提示注入事件的应急响应演练。
