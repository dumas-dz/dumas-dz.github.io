# 分布式系统

本主题关注部分失败时如何保持正确、可恢复和可解释：一致性、缓存、事务、幂等、补偿与对账。

## 学习顺序

1. 阅读[分布式一致性、缓存、事务与幂等](./arch-distributed-overview.md)。
2. 为一个跨服务操作定义一致性窗口、幂等键、补偿动作和对账指标。
3. 练习超时、重复、乱序、消息丢失和下游部分成功场景。
4. 结合[微服务系统与治理](../microservice/README.md)设计超时、重试、熔断和追踪。
