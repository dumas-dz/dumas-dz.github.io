# 架构与分布式

架构回答“系统为什么这样组织”，分布式工程回答“系统在部分失败时如何继续正确运行”。本目录把取舍、边界、一致性、故障治理和可观测性放在一起，避免只学组件不学系统。

## 学习路线

1. 先读[架构知识体系](./basis/arch-basis-overview.md)：质量属性、边界、视图和 ADR。
2. 再读[分布式一致性、缓存、事务与幂等](./distributed/arch-distributed-overview.md)：一致性模型、缓存、Saga/TCC/Outbox、对账和幂等。
3. 最后读[微服务系统与治理](./microservice/arch-microservice-overview.md)：拆分、契约、流量、配置、发布和观测。
4. 与[框架与中间件](../framework/README.md)、[工程规范](../dev-spec/README.md)和[数据库](../db/README.md)交叉练习。

## 架构评审问题

- 目标、规模、假设和 SLO 是否可测量？
- 每个跨进程边界是否有 timeout、幂等、重试、熔断、降级和追踪？
- 数据事实源、缓存、投影和消息的延迟/丢失/重复边界是什么？
- 发布、扩容、故障域、回滚、备份恢复是否有演练？
- 团队 owner、值班、成本、安全和合规是否随架构一起设计？
