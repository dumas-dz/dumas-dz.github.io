# 架构基础

本主题关注系统为什么这样组织：业务目标、质量属性、边界、依赖、决策和演进证据。

## 学习顺序

1. 阅读[架构知识体系](./arch-basis-overview.md)。
2. 选择一个真实模块，写出目标、约束、质量属性和至少两个备选方案。
3. 用 ADR 记录取舍、后果、复审条件和验证指标。
4. 继续学习[分布式一致性、缓存、事务与幂等](../distributed/README.md)。

## 检查表

- [ ] 目标与非目标可验证。
- [ ] 边界、事实源、依赖和 owner 明确。
- [ ] 性能、可用性、安全、成本有量化约束。
- [ ] 决策记录包含备选方案、理由、后果和复审条件。
