# Spring Cloud 分布式治理

本目录覆盖多服务架构中的入口、注册发现、配置、限流熔断、安全和可观测性。内容重点不是堆叠组件，而是定义边界、失败模式、版本兼容和降级策略。

## 学习目标

- 理解服务发现、配置中心、网关、熔断限流和分布式追踪。
- 能组合 Gateway、Nacos、Sentinel、OAuth2/JWT 并定义安全边界。
- 能在 Spring Cloud Alibaba、Netflix、Tencent 发行版之间做生命周期和版本选型。
