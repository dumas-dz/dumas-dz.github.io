# Spring Boot 工程实践

本目录把 Spring Framework 能力组装为可部署服务，覆盖自动配置、应用生命周期、HTTP API、数据访问、事务、安全和可观测性。

## 学习目标

- 理解 Starter、自动配置、外部化配置、Profile 和生命周期。
- 设计稳定 API、错误契约、超时、幂等和安全响应。
- 正确使用 JDBC/JPA、事务、连接池和数据库异常处理。
