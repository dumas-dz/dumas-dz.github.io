# Spring Framework

本目录聚焦 Spring Framework 核心，不直接覆盖 Spring Boot 自动配置和 Spring Cloud 分布式治理。学习重点是容器对象模型、代理增强、Web 请求处理和扩展点。

## 学习目标

- 理解 IoC 容器、Bean 生命周期、依赖查找和作用域。
- 掌握 AOP 代理限制、事务边界和自定义切面。
- 掌握 DispatcherServlet、参数解析、异常处理和异步请求。
