## 一个面向真实开发的知识库

这里记录我作为 **Java / AI 应用开发工程师** 的学习、设计与实践，并持续扩展 Web3 开发方向。内容以学习者视角编写，不追求名词堆叠，而是围绕三个问题展开：

- **怎么设计**：如何选择 Agent、RAG、Workflow、MCP 或传统服务方案。
- **怎么实现**：如何完成接口、状态、检索、工具调用、流式响应与数据闭环。
- **怎么交付**：如何评测、监控、保障安全、部署上线并控制成本。

建议从[开发者 AI 应用知识地图](/md/)开始，或直接阅读[项目案例](/portfolio/)。
