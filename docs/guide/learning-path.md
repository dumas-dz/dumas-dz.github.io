# 技术学习路线

这里按“想学习技术并做出项目”的视角，将知识库划分为三条主线。你可以选择一条主攻，也可以用 Java 作为工程底座、AI 或 Web3 作为应用方向。

## 三条主线怎么选

| 主线 | 核心能力 | 推荐项目 | 学习入口 |
| --- | --- | --- | --- |
| Java 技术栈 | 编程基础、并发、JVM、Spring、数据库、消息与分布式系统 | 后端服务、订单系统、网关、微服务 | [Java](/md/java/) |
| AI 应用技术栈 | Prompt、RAG、Agent、Workflow、MCP、评测和部署 | 企业知识库、智能客服、工具型 Agent | [AI 应用](/md/llm/) |
| Web3 开发技术栈 | 区块链、Solidity、智能合约、安全、DApp、索引和部署 | ERC-20/721、投票、众筹、链上数据 DApp | [Web3](/md/web3/) |

## 通用学习方法

1. **先建立地图**：先读领域 `README.md`，知道知识之间的关系。
2. **再做最小实践**：每个主题先完成一个小而可运行的例子。
3. **补工程能力**：测试、日志、错误处理、安全、性能和部署不能留到最后。
4. **用项目串联**：至少完成一个包含数据、接口、业务流程和交付的项目。
5. **最后复盘**：整理架构决策、失败案例、面试问题和后续优化。

## AI 应用开发路线

这条路线面向已有后端开发经验、希望建立企业级 AI 应用开发能力的工程师。

## 阶段 1：模型与接口基础

**目标**：理解 LLM 的能力边界，能够调用模型并稳定处理输入输出。

- Token、上下文窗口、温度与采样参数
- Prompt、Few-shot、结构化输出与校验
- Tool Calling、SSE 流式响应、错误重试
- 入口：[AI 基础](/md/llm/foundations/)

**产出**：一个支持结构化输出和流式响应的 FastAPI 对话接口。

## 阶段 2：RAG 知识应用

**目标**：把企业文档变成可检索、可引用、可评估的知识服务。

- 摄取、解析、清洗、切分、Embedding
- 混合检索、过滤、重排、引用和权限
- 召回评测、忠实度评测和回归集
- 入口：[RAG 与知识库](/md/llm/rag/)

**产出**：带引用、拒答和评测报告的 RAG 问答服务。

## 阶段 3：Agent 与工具闭环

**目标**：让模型在受控状态和权限下调用工具完成业务任务。

- 意图路由、槽位填充、计划执行
- 工具 schema、超时、重试、幂等和审计
- 短期上下文、长期记忆、用户画像
- 入口：[Agent 架构](/md/llm/agent/)

**产出**：能创建工单并回写结果的单 Agent 应用。

## 阶段 4：Workflow 与多 Agent

**目标**：用明确的流程、状态和边界处理复杂业务。

- LangGraph 状态机、条件边、检查点
- Router + 垂直 Agent、监督者和流水线
- MCP 工具服务、Dify 工作流集成
- 入口：[Workflow](/md/llm/workflow/)、[MCP](/md/llm/mcp/)

**产出**：多 Agent 协作的智能客服或业务处理流程。

## 阶段 5：生产工程

**目标**：把 Demo 提升为可观测、可恢复、可演进的系统。

- 异步任务、消息队列、缓存、幂等、断路器
- Trace、日志、指标、成本和延迟监控
- Prompt/数据/代码/模型版本治理
- 入口：[AI 工程化](/md/llm/engineering/)

**产出**：具备监控、审计、重放和降级能力的服务。

## 阶段 6：质量、安全与部署

**目标**：证明系统有效，并以可控风险和成本上线。

- 离线评测、在线反馈、红队测试
- 提示注入、越权、数据泄露、输出安全
- Ollama、vLLM、Dify、LoRA、容量规划
- 入口：[评测](/md/llm/evaluation/)、[安全](/md/llm/security/)、[部署](/md/llm/deploy/)

**产出**：评测基线、安全检查表、部署与回滚方案。
