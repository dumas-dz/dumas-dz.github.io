# 知识库指南

## 如何使用

- 使用[知识地图](/md/)查看完整技术体系和学习顺序。
- 使用领域目录的 `README.md` 了解主题覆盖范围。
- 通过项目案例理解知识如何组合为可运行、可维护的系统。
- 通过[内容规范](./content-standard.md)了解文档的统一结构。

## 如何维护

1. 新增内容前先检查知识地图，避免重复。
2. 一个文档只解决一个清晰问题，跨主题内容使用链接。
3. 代码、版本和配置必须标明适用范围。
4. 在领域 `README.md` 更新学习路线、状态和关联文档。
5. 发布前运行 `pnpm run docs:build` 检查构建和链接。

## 维护状态

| 内容域 | 说明 |
| --- | --- |
| AI 应用开发 | 核心内容持续扩充，优先保障工程实践 |
| Java / Spring / DB / Middleware | 以常用技术栈和排查方法为主线 |
| 项目案例 | 用架构决策、实施过程和复盘组织内容 |
| 网站体验 | 持续优化导航、可读性和检索体验 |
